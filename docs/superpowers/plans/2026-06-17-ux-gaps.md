# UI/UX Gaps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close six concrete interaction gaps — missing feedback states, dead click targets, invisible empty states, and a broken drop zone — that make the app feel unfinished during normal use.

**Architecture:** All changes are in existing component files. No new stores, no new routes. Each task is independently shippable. Design system rules apply throughout: no radius >4px, no glassmorphism, opacity hierarchy via Monitor White stack.

**Tech Stack:** TypeScript, React, Framer Motion, D3, Vitest + React Testing Library

## Global Constraints

- No `border-radius` above 4px on any element
- No hardcoded accent colors — use `accentColour` prop or `var(--accent-color)`
- All opacity values for text must be ≥0.45 (WCAG AA Large on `#0d0d0d`)
- Uppercase + wide tracking for labels; sentence case for track titles
- Use `pnpm`, not `npm` or `yarn`
- Run `pnpm build` after every task

### Task 3: Make genre graph labels clickable

**Files:**

- Modify: `src/components/library/GenreForceGraph.tsx`

**Context:** Clicking a genre node circle selects it, but clicking the text label below the node does nothing — the click target is smaller than it looks. Labels should forward clicks to the same handler as the circle, and should show `cursor: pointer`.

**Interfaces:**

- Produces: nothing consumed by other tasks

- [ ] **Step 1: Wire click and cursor on labels**

In `src/components/library/GenreForceGraph.tsx`, find the label enter selection (the `.enter().append('text')` block). It currently just sets text content and animates in. Add click and cursor handling to match the node circles:

```ts
labelSel
  .enter()
  .append('text')
  .style('opacity', 0)
  .style('cursor', 'pointer')
  .on('click', (_event, d) => {
    const current = activeGenreRef.current
    onSelectRef.current(current === d.id ? null : d.id)
  })
  .on('mouseenter', function () {
    d3.select(this).style('opacity', 1)
  })
  .on('mouseleave', function (_event, d) {
    // Reset to the tick-driven opacity (0.5 + bassPower * 0.5 at rest ≈ 0.5)
    d3.select(this).style('opacity', 0.5)
  })
  .text(d => d.label)
  .transition()
  .duration(400)
  .style('opacity', 1)
```

Also update the merged label selection (the `root.select('g.labels').selectAll(...)` block below) to reflect active state on the label text — match the stroke highlight used on the node circles:

```ts
root
  .select('g.labels')

  .style('font-weight', d => (activeGenreRef.current === d.id ? '700' : '400'))
  .style('fill', d => (activeGenreRef.current === d.id ? '#fff' : 'inherit'))
```
